# Escopo de licenças e redistribuição

Código próprio e documentação original AIDA: Apache-2.0. Obras de terceiros mantêm
licenças. Confirme titularidade das contribuições antes de publicar. Preserve avisos e
identifique modificações. Texto oficial Apache em inglês é autoritativo. Nome/logos não
implicam aprovação de forks; mídias do usuário continuam suas.

Qt/PySide/Shiboken e FFmpeg selecionado mantêm obrigações LGPL. Preserve bibliotecas
substituíveis, avisos completos e fontes correspondentes exatos. Não proíba engenharia
reversa para depurar modificações das bibliotecas. Hook PyInstaller adaptado mantém
aviso GPL/exceção original. Ponte NVIDIA combina fonte próprio com oito helpers/headers
MIT em native/vendor. Headers/import library CUDA são entradas de build; não inclua
CUDA Toolkit no aplicativo.

Runtime Microsoft segue termos próprios. Revise os arquivos distribuídos e seus avisos
na revisão de dependências de cada release. Scripts não concedem aprovação jurídica. O relatório
verifica hashes/avisos. Consulte docs/ASSETS.md; não declare imagens incertas como código próprio.

Avisos: ../../THIRD_PARTY_NOTICES.md e installer/third_party_texts. Fontes correspondentes
são reunidos por bootstrap_sources e stage_distribution_materials.
