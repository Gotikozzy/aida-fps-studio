# Contributing / Contribuindo

EN: Use Python 3.12 on Windows. Follow README and BUILD, create a focused branch and
submit a pull request describing the problem, resulting behavior and actual validation.
Do not commit footage, secrets, caches or binaries. Contributions are submitted under
the project's Apache-2.0 terms; retain upstream notices and confirm you have the rights.
No commercial dual-license contribution agreement is required. Discuss major changes
before implementation and record an ADR. Changes to measurement need versioned methods,
PTS/provenance evidence and regression tests; performance claims need stated hardware,
input, cache state, repetitions and uncertainty. Keep PT/EN docs aligned. Review all
external pull requests; review build/workflow changes particularly carefully. Never expose
signing credentials to fork PRs. GPU tests are optional locally, not startup requirements.

PT: Use Python 3.12 no Windows. Siga README e BUILD, crie uma branch focada e abra PR
com problema, comportamento resultante e validação realizada. Não envie vídeos, segredos,
caches ou binários. Contribuições seguem Apache-2.0; preserve avisos upstream e confirme
seus direitos. Não exigimos acordo de licença comercial dupla. Discuta mudanças amplas
e registre ADR. Medição exige método versionado, evidência PTS/proveniência e regressão;
desempenho exige hardware, entrada, estado de cache, repetições e incerteza. Atualize os
dois idiomas. Revise PRs externos, especialmente builds e workflows; não exponha segredos
a forks. Testes GPU locais são opcionais, sem requisito GPU na abertura.
