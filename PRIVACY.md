# Privacy / Privacidade

EN: Video decoding, indexing, analysis, thumbnails and export run locally. No application
feature uploads videos, frames, projects or measurement results. On startup, the updater
requests https://detonandogueek.com.br/aida/update.json. The server/network operators can
observe normal connection metadata such as IP and request time. This repository does
not establish a server log-retention period; the site operator must publish its actual
hosting policy before public release. Do not claim zero network traffic.

Disable automatic checks by selecting the optional offline installer component, or create
an empty `.disable-update-check` beside the installed EXE (source checkout: repository
root). Delete it to re-enable. Analysis works offline. Downloads and installer launch
require confirmation. Help/site links open only on user action. No advertising or analytics
SDK is required. User-triggered links have the destination site's privacy policy.

Data and settings use platformdirs under the current Windows user profile; logs rotate
locally and may contain paths. Project files reference user source files; they are not
permission to publish those files. Inspect diagnostics before sharing. Uninstall preserves
user projects, settings and cache; use the app's cache controls and delete user-owned data
explicitly if desired. The offline marker is preserved on upgrades and may remain on uninstall.

PT: Decodificação, indexação, análise, miniaturas e exportação são locais. Nenhuma função
envia vídeos, frames, projetos ou medições. Na abertura, o atualizador consulta o endereço
acima. Servidor e operadores de rede podem observar IP e horário da conexão. Este
repositório não determina retenção de logs do servidor; o operador deve publicar sua
política real antes da release pública. Não se declara ausência total de rede.

Desative consultas pelo componente opcional offline do instalador ou crie o arquivo vazio
`.disable-update-check` ao lado do EXE; nos fontes, na raiz. Apague-o para reativar.
Análises funcionam offline. Download e execução do instalador exigem confirmação.
Links de ajuda/site abrem por ação do usuário e seguem a política do destino.
Não há SDK obrigatório de publicidade ou analytics.

Dados e preferências usam platformdirs no perfil Windows. Logs rotativos podem conter
caminhos. Projetos referenciam fontes do usuário sem autorizar sua publicação. Revise
diagnósticos antes de compartilhar. Desinstalar preserva projetos, preferências e cache;
use os controles do app e remova seus dados explicitamente se desejar. O marcador
offline é preservado em upgrades e pode permanecer após desinstalar.
