Privacy: video processing and analysis are local. On startup the application checks
https://detonandogueek.com.br/aida/update.json for a newer version. The server receives
normal connection metadata, including IP. Videos, projects, frames and results are
not uploaded. Downloading and launching an update requires confirmation.
Disable automatic checks by installing the optional offline-mode component or by
creating an empty .disable-update-check file in the program directory. Delete that
file to re-enable checks. Offline mode does not change measurements.
