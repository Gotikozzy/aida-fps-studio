# Corresponding sources / Fontes correspondentes

Generated content is excluded from Git. Run `python scripts/bootstrap_sources.py --extract`,
build the validated media composition and run `python scripts/stage_distribution_materials.py`.
Public binary releases must include complete corresponding sources and original notices.
Do not replace these obligations with a link to a moving upstream branch.

Conteúdo gerado fica fora do Git. Execute os comandos acima; releases binárias
públicas devem incluir fontes correspondentes completos e avisos originais.
