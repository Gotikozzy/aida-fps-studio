# Security / Segurança

EN: Only the latest published release receives security fixes. Do not post credentials,
private captures or exploitable details in public issues. Use
[GitHub private vulnerability reporting](https://github.com/Gotikozzy/aida-fps-studio/security/advisories/new)
for sensitive reports. If unavailable, contact the maintainer through the official site
https://detonandogueek.com.br/aida to request a private channel. No response-time promise
is made. Maintainers reproduce, assess, fix, validate, release and disclose affected/fixed versions.

Trust boundaries: video containers, .aida files and downloaded ZIPs are untrusted.
SHA-256 checks do not independently authenticate a compromised update origin.
The current updater does not enforce Authenticode validation. Keep update manifests
and release publication access restricted. See CODE_SIGNING.md and docs/en/UPDATES.md.

PT: Apenas a release mais recente recebe correções de segurança. Não publique segredos,
capturas privadas ou detalhes exploráveis. Use o
[relato privado do GitHub](https://github.com/Gotikozzy/aida-fps-studio/security/advisories/new).
Se indisponível, solicite canal privado pelo contato do site oficial antes de enviar
detalhes sensíveis. Não há prazo prometido. O fluxo é reproduzir, avaliar, corrigir,
validar, publicar e informar versões afetadas/corrigidas.

Vídeos, projetos e ZIPs são entradas não confiáveis. SHA-256 não autentica sozinho um
servidor de atualização comprometido. O atualizador não exige validação Authenticode.
Restrinja publicação de releases e manifesto; consulte a política de assinatura.
