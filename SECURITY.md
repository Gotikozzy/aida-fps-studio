# Security / Segurança

EN: Only the latest published release receives security fixes. Do not post credentials,
private captures or exploitable details in public issues. Until GitHub private vulnerability
reporting is configured, use the maintainer contact channel on
https://detonandogueek.com.br/aida and request a private reporting route before sending
sensitive details. No response-time promise is made. Maintainers reproduce, assess,
fix, validate, release and disclose affected/fixed versions. Enable GitHub private
vulnerability reporting before inviting public contributions.

Trust boundaries: video containers, .aida files and downloaded ZIPs are untrusted.
SHA-256 checks do not independently authenticate a compromised update origin.
The current updater does not enforce Authenticode validation. Keep update manifests
and release publication access restricted. See CODE_SIGNING.md and docs/en/UPDATES.md.

PT: Apenas a release mais recente recebe correções de segurança. Não publique segredos,
capturas privadas ou detalhes exploráveis. Enquanto o relato privado do GitHub não
estiver configurado, use o contato do mantenedor no site acima para solicitar um canal
privado antes de enviar detalhes sensíveis. Não há prazo de resposta prometido. O fluxo
é reproduzir, avaliar, corrigir, validar, publicar e informar versões afetadas/corrigidas.
Ative relatos privados no GitHub antes de receber contribuições públicas.

Vídeos, projetos e ZIPs são entradas não confiáveis. SHA-256 não autentica sozinho um
servidor de atualização comprometido. O atualizador não exige validação Authenticode.
Restrinja publicação de releases e manifesto; consulte a política de assinatura.
